# WDTD 星火日曆

以多人共享為核心的行事曆 App，採 Expo + React Native + TypeScript。

## v0.5 開發進度

- 動態月曆：上 / 下月切換與今天快速定位
- 多日曆顯示 / 隱藏
- 單日行程底部面板
- 新增、編輯、刪除行程
- 全天、日期、時間、地點、備註
- AsyncStorage 行程、日曆與成員本機持久化
- 重複行程：不重複 / 每天 / 每週 / 每月 / 每年
- 重複行程已實際顯示在月曆與單日清單
- 提醒設定：不提醒 / 開始時 / 10 分鐘前 / 30 分鐘前 / 1 小時前 / 1 天前
- 建立、編輯、刪除多個日曆
- 日曆自訂顏色
- 私人 / 共享日曆類型
- 共享日曆成員資料模型
- 成員權限：擁有者 / 可編輯 / 僅查看
- 共享日曆邀請碼資料模型與 8 碼邀請碼產生器
- 日曆編輯權限與成員管理權限判定工具
- GitHub Actions：每次 push 自動留下更新紀錄並執行 TypeScript 檢查

## 執行

```bash
npm install
npx expo start
```

Android 可使用 Expo Go 掃描 QR Code 預覽。
