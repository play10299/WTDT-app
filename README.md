# WDTD 星火日曆

以多人共享為核心的行事曆 App，採 Expo + React Native + TypeScript。

## v0.2 已完成

- 動態月曆：可切換上個月 / 下個月
- 「今天」快速定位，今日日期醒目標示
- 點擊跨月日期會自動切換月份
- 多日曆顯示 / 隱藏
- 單日行程底部面板
- 新增與編輯行程
- 刪除行程確認
- 日期、開始 / 結束時間、全天行程
- 選擇私人 / 星火共享日曆
- 地點與備註欄位
- AsyncStorage 本機持久化，重新開啟 App 仍保留行程
- 日曆清單、最新動態、其他頁面
- 四分頁底部導覽

## 執行

```bash
npm install
npx expo start
```

Android 可使用 Expo Go 掃描 QR Code 預覽。
