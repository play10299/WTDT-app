# WDTD 星火日曆

以多人共享為核心的行事曆 App。第一版採 Expo + React Native + TypeScript。

## 已完成

- 月曆首頁（2026/11 demo）
- 多日曆顯示/隱藏
- 日期點擊與單日行程底部面板
- 新增行程介面與本機狀態新增
- 日曆清單
- 最新動態
- 其他/設定首頁
- 四分頁底部導覽
- WDTD 星火品牌色

## 執行

```bash
npm install
npx expo start
```

Android 可使用 Expo Go 掃描 QR Code 預覽。
