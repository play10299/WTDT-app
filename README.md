# WDTD 星火日曆

以多人共享為核心的行事曆 App，採 Expo + React Native + TypeScript。

## v0.3 開發進度

- 動態月曆：可切換上個月 / 下個月
- 「今天」快速定位，今日日期醒目標示
- 點擊跨月日期會自動切換月份
- 多日曆顯示 / 隱藏
- 單日行程底部面板
- 新增、編輯與刪除行程
- 日期、開始 / 結束時間、全天行程
- 選擇私人 / 星火共享日曆
- 地點與備註欄位
- AsyncStorage 本機持久化
- 日曆資料持久化基礎
- 重複行程資料模型：每天 / 每週 / 每月 / 每年
- 提醒資料模型：開始時 / 10 分鐘前 / 30 分鐘前 / 1 小時前 / 1 天前
- 重複行程日期判定工具
- GitHub Actions：每次 push 自動留下更新紀錄並執行 TypeScript 檢查

## 執行

```bash
npm install
npx expo start
```

Android 可使用 Expo Go 掃描 QR Code 預覽。
